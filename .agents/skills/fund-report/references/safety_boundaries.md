# Safety Boundaries

## Product Boundary

This Skill supports fund metric analysis reports for research assistance. It is not an investment advisory service.

## Required Safety Behavior

The report must:

- state that it is based on historical structured indicators
- state that it does not constitute investment advice
- avoid buy, sell, hold, timing, and allocation recommendations
- avoid future-return predictions
- avoid guarantees or certainty claims
- acknowledge missing data and uncertainty
- cite input metrics for important conclusions where possible

## Prohibited Recommendation Expressions

Do not output expressions equivalent to:

- 买入
- 卖出
- 持有
- 加仓
- 减仓
- 清仓
- 建仓
- 抄底
- 止盈
- 止损
- 配置比例
- 仓位建议
- 核心配置
- 底仓配置
- 组合配置
- 适合作为组合配置
- 适合购买
- 不适合购买

These terms may appear only when explicitly explaining that the report does not provide such advice.

## Prohibited Prediction Expressions

Do not output expressions equivalent to:

- 未来收益将
- 预计收益
- 必然上涨
- 必然下跌
- 保证收益
- 稳赚
- 无风险
- 确定跑赢
- 一定跑赢

## Allowed Analytical Expressions

Allowed:

- "历史收益表现"
- "在观察期内"
- "相对基准表现"
- "同类分位"
- "回撤幅度较大"
- "波动水平需要关注"
- "该结论受限于数据完整性"

## Required Disclaimer

Each report must include a section stating:

```markdown
本报告基于已提供的历史结构化指标生成，仅用于研究和信息整理，不构成任何买入、卖出、持有、择时或仓位配置建议，也不构成对未来收益的预测、承诺或保证。
```
