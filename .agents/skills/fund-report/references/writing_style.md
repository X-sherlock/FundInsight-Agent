# Writing Style

## Language

Use concise professional Chinese.

## Tone

The tone should be analytical, neutral, and non-promotional. Avoid marketing language, emotional claims, and direct investment action language.

## Formatting

- Output Markdown report content inside `<report_markdown>...</report_markdown>` when instructed by the runtime prompt.
- Output chart specification JSON inside `<chart_specs_json>...</chart_specs_json>` when instructed by the runtime prompt.
- Use the required v0.2 headings from `report_structure.md`.
- Use at least three Markdown data tables.
- Use at least five chart placeholders and write an interpretation for each.
- Use bullets for core conclusions, strengths, risks, scenarios, and data limitations.
- Keep paragraphs short.
- Include metric windows and units where possible.

## Preferred Wording

Use:

- "历史表现"
- "观察区间"
- "相对基准"
- "相对同类"
- "波动水平"
- "回撤压力"
- "收益质量"
- "风险调整后表现"
- "数据限制"
- "不构成投资建议"

Avoid:

- "建议买入"
- "建议卖出"
- "建议持有"
- "未来将上涨"
- "收益确定"
- "稳赚"
- "适合重仓"
- "可以抄底"

## Conclusion Style

The report may end with a neutral synthesis of observed characteristics and limitations. It must not provide an action recommendation.
