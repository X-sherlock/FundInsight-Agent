# Writing Style

## Language

Use concise professional Chinese.

## Tone

The tone should be analytical, neutral, and non-promotional. Avoid marketing language and emotional claims.

## Formatting

- Output Markdown only.
- Use the required headings from `report_structure.md`.
- Use tables for compact metric overview.
- Use bullets for data limitations.
- Keep paragraphs short.
- Include metric windows and units where possible.

## Preferred Wording

Use:

- "历史表现"
- "观察区间"
- "相对基准"
- "波动水平"
- "回撤压力"
- "风险调整后表现"
- "数据限制"
- "不构成投资建议"

Avoid:

- "建议买入"
- "建议卖出"
- "建议持有"
- "未来将上涨"
- "收益确定"
- "稳赚"
- "适合重仓"
- "可以抄底"

## Conclusion Style

The report may end with a neutral synthesis of observed characteristics and limitations. It must not provide an action recommendation.
